# ruruDown

bilibili クライアントが**端末にすでにキャッシュ済み**の動画を、通常の `mp4` / `m4a` / `xml` ファイルにエクスポートします。  
ネットワークからのダウンロード、アップロード、キャッシュフォルダへの書き込みは行いません。一度読み取り、ストリームコピーで出力します。

> **配布専用リポジトリ**  
> このリポジトリには APK、ドキュメント、および LGPL コンポーネントの素材のみが含まれます。  
> アプリケーション自体のソースコードは公開されていません（無料のクローズドソース — [LICENSE](LICENSE.ja.md) を参照）。

前提条件：Shizuku

bilibili のキャッシュは別アプリのプライベートディレクトリにあり、通常の権限ではアクセスできません。ruruDown は Shizuku が提供するファイルチャネルを通じて読み取り専用でアクセスします。データは Binder 経由で転送されず、リモートファイルディスクリプタ経由で読み取られます。

セットアップ手順

1. Shizuku をインストールして起動します（ADB または root 不要の方法）。
2. ruruDown を開き、ホーム画面で「認証」をタップし、Shizuku のダイアログで許可します。
3. ホーム画面に戻り、「再スキャン」をタップします。

Shizuku がない場合でもアプリは起動しますが、キャッシュは検出されません。設定 → 診断で、どの段階で失敗しているかを確認できます。

---

エクスポート先フォルダ

デフォルトは Download/ruruDown です。
変更するには、設定 → エクスポート先フォルダでシステムのディレクトリ選択ツールを使用します。
Download 以外のフォルダを選択する場合、システム設定で「すべてのファイルへのアクセス」権限が別途必要な場合があります。

機能

- キャッシュされた動画をスキャンし、長さ・サイズ・日時で並べ替え。カバー画像、投稿者、画質、パート情報を表示。
- 動画 .mp4 をエクスポート（音声・映像ストリームコピー、再エンコードなし、画質はキャッシュと完全一致）。
- 音声 .m4a をエクスポート。
- 弾幕 .xml をエクスポート（bilibili XML 形式、プレイヤーで直接読み込み可能）。
- バッチエクスポートキュー。フォアグラウンドサービス＋通知で進捗表示。画面を離れても継続。
- 内蔵プレイヤー：動画は横向き全画面、音声はミニプレイヤーバー。
- 音声ページで長押しにより複数選択し、一括削除可能。
- UI 言語：English / 日本語 / 简体中文 / 繁體中文。システム設定に従うか手動で指定可能。

---

プライバシー

本アプリにはネットワーク関連のコードは一切含まれていません（FFmpeg 自体も --disable-network でビルドされています）。
アカウント、解析、クラッシュレポートは一切ありません。すべてのデータは端末内に保存されます。インデックスデータベースとサムネイルはアプリのプライベートディレクトリにあり、設定 → ローカルキャッシュを消去でいつでも削除できます。
