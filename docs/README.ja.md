ruruDown は、bilibili クライアントが**端末にすでにキャッシュ済み**の動画を、通常の
`mp4` / `m4a` / `xml` / `srt` / `txt` ファイルとして書き出します。書き出しはロスレスで、
画質はキャッシュと完全に一致します。ダウンロードもアップロードも行わず、
キャッシュフォルダを変更することもありません。

> **これは配布専用リポジトリです。** APK、そのドキュメント、および同梱 FFmpeg ライブラリに
> ついて LGPL が要求する素材のみを収めています。ruruDown は無料のクローズドソースです
> （[LICENSE](LICENSE.ja.md) を参照）。

## ダウンロード

APK は [Releases ページ](https://github.com/Uminory/ruruDown/releases)、または
リポジトリの [`apk/`](../apk/) から直接取得できます。

## 前提条件：Shizuku

bilibili のキャッシュは別アプリのプライベートフォルダにあり、通常の権限では
アクセスできません。ruruDown は [Shizuku](https://shizuku.rikka.app/) を通じて
読み取り専用でアクセスします。

1. Shizuku をインストールして起動します（ADB または root 不要の方法）。
2. ruruDown を開き、ホーム画面で**認証**をタップし、Shizuku のダイアログで許可します。
3. ホーム画面に戻り、**再スキャン**をタップします。

スキャンとキャッシュからの書き出しには Shizuku の許可が必要です。端末にあるローカル MP4
からのクリップ書き出しは Shizuku なしでも利用できます。アクセスの問題は**設定 → 診断**で
確認できます。

## エクスポート先フォルダ

デフォルトは `Download/ruruDown` です。**設定 → エクスポート先フォルダ**から、
端末または外部ストレージの任意の共有フォルダを選べます。クラウド、アプリ専用フォルダ、
`Android` データ配下には書き出せません。「すべてのファイルへのアクセス」は要求しません。

## 機能

- キャッシュされた動画をスキャン：国内版・国際版 bilibili クライアントのキャッシュを
  同じライブラリに統合。変更版クライアント向けのスキャンパス追加にも対応。
  長さ・サイズ・日時で並べ替え、カバー画像・投稿者・画質・パート情報を表示。
- ライブラリーと音声ページをタイトル・投稿者・BV ID・ファイル名で検索。
- 動画を `.mp4` として書き出し。画質はロスレスで、書き出し後すぐギャラリーに現れます。
- 音声を `.m4a` として書き出し。
- 詳細ページの**プロパティ**を展開して、動画の実際のメディア情報を表示。
- 弾幕を `.xml` として書き出し（bilibili XML 形式、プレイヤーで直接読み込み可能）。
- キャッシュ字幕を `.srt` または本文のみの `.txt` として、動画と同名で書き出し。
- 動画と同じフォルダにある同名 `.srt` を CC ボタンで表示。自分で入れた字幕ファイルも利用可能。
- クリップ切り出し：ミリ秒単位の時刻入力とプレイヤーの「現在時刻」ボタン。
  映像または音声のみのクリップを書き出せます。
- キャッシュ消去後も書き出し記録を保持。保存先フォルダを変更しても既存の書き出しを識別できます。
- バッチエクスポートキュー。通知に進捗を表示し、画面を離れても継続します。
- 内蔵プレイヤー：縦長動画は縦向き全画面、横長動画は横向き全画面、音声はミニプレイヤーバー。
  イヤホン切断時に一時停止し、再生終了後は先頭から再再生できます。
- 弾幕は黒帯を含むプレイヤー全体に表示（ツールバーで切替、**設定 → 弾幕設定**で調整）。
- 音声ページで長押しして複数選択し、一括削除。
- ライブラリー・音声・設定のスクロール位置を保持し、戻ったときに復元。
- UI 言語：English / 日本語 / 简体中文 / 繁體中文。システム設定に従うか手動で指定可能。

## プライバシー

本アプリにはネットワーク機能が一切ありません。アカウント、解析、クラッシュレポートも
ありません。すべてのデータは端末内に留まります。**設定 → ローカルキャッシュを消去**は
メディアのスキャンキャッシュとサムネイルを削除します。既存の書き出しを識別できるよう、
書き出し記録は保持します。
