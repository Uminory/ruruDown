ruruDown は、bilibili クライアントが**端末にすでにキャッシュ済み**の動画を、通常の
`mp4` / `m4a` / `xml` / `srt` / `txt` ファイルとして書き出します。ダウンロードもアップロードも行わず、
キャッシュフォルダへ書き込むこともありません。ストリームコピーで映像・音声の圧縮データを
保持し、再エンコードは行いません。

> **これは配布専用リポジトリです。** APK、そのドキュメント、および同梱 FFmpeg ライブラリに
> ついて LGPL が要求する素材のみを収めています。アプリケーション自体のソースコードは
> 公開していません（無料のクローズドソース、[LICENSE](LICENSE.ja.md) を参照）。

APK は [Releases ページ](https://github.com/Uminory/ruruDown/releases)、または
リポジトリの [`apk/`](../apk/) から直接取得できます。

（**証明書**の SHA-256。APK ファイルの SHA-256 ではありません）：

## 前提条件：Shizuku

bilibili のキャッシュは別アプリのプライベートディレクトリにあり、通常の権限では
アクセスできません。ruruDown は [Shizuku](https://shizuku.rikka.app/) を通じて
読み取り専用でアクセスします。データは Binder 経由で転送されず、リモートファイル
ディスクリプタ経由で読み取られます。

1. Shizuku をインストールして起動します（ADB または root 不要の方法）。
2. ruruDown を開き、ホーム画面で**認証**をタップし、Shizuku のダイアログで許可します。
3. ホーム画面に戻り、**再スキャン**をタップします。

スキャンとキャッシュからの書き出しには Shizuku の許可が必要です。認識済みのローカル MP4
からのクリップ書き出しは Shizuku なしでも利用できます。アクセスの問題は**設定 → 診断**で確認できます。

## エクスポート先フォルダ

デフォルトは `Download/ruruDown` です。**設定 → エクスポート先フォルダ**から、
システムのフォルダー選択画面で端末または外部ストレージの共有フォルダーを選べます。
システムの外部ストレージプロバイダーのみ対応し、クラウド、アプリ専用フォルダー、
`Android` 配下には書き出せません。「すべてのファイルへのアクセス」は要求しません。
Android 8–10 の既定フォルダーでは必要時にストレージ権限を求め、SAF で選んだ共有
フォルダーではそのフォルダーの許可を使います。

同じ実フォルダーへのアクセス方法を変更しても、検証済みの所有情報を保持し、ファイルを
コピーしません。中断した一時ファイルは専用記録で回収します。システムの時間制限や
長時間の無応答では自動停止し、理由をエクスポートキューに表示します。

## 機能

- キャッシュされた動画をスキャン（国内版・国際版 bilibili クライアントのキャッシュを
  自動認識して同じライブラリに統合。変更版クライアント向けのスキャンパス追加にも対応）。
  長さ・サイズ・日時で並べ替え。カバー画像、投稿者、画質、パート情報を表示。
- 動画を `.mp4` として書き出し（音声・映像ストリームコピー、再エンコードなし、画質は
  キャッシュと完全一致）。書き出し後すぐシステムのメディアインデックスに登録するので、
  再起動や定期スキャンを待たずにギャラリーに現れます。
- 音声を `.m4a` として書き出し。
- 弾幕を `.xml` として書き出し（bilibili XML 形式、プレイヤーで直接読み込み可能）。
- キャッシュ字幕を検出した場合のみ詳細に字幕出力を表示し、`.srt`／本文のみの `.txt` を動画と同名で書き出せます。
- 動画と同じフォルダーにある同名 `.srt` を CC ボタンで表示。字幕の出力履歴は不要で、字幕の異常は動画再生へ影響しません。
- ミリ秒単位の時刻入力とプレイヤーの「現在時刻」ボタンでクリップを切り出し。
  認識済みのローカル MP4 を優先し、利用できない場合はキャッシュへ切り替えます。音声のみも選択可能。
- 成功した書き出し記録はキャッシュ消去後も保持。読みやすいファイル名と、保存先変更時の検証付き移行に対応。
- バッチエクスポートキュー。フォアグラウンドサービス＋通知で進捗表示し、画面を離れても
  継続します。
- 内蔵プレイヤー：縦長動画は縦向き全画面、正方形・横長動画は横向き全画面。
  音声はミニプレイヤーバー。音声フォーカスとイヤホン切断時の一時停止に対応し、
  再生終了後に再生を押すと先頭から再開します。
- 弾幕は黒帯を含むプレイヤー全体に表示（ツールバーで切替、**設定 → 弾幕設定**で調整）。
  一時停止中は必要時のみ描画し、不正または解析上限を超える再生用 XML は通知せず無効化。
  元の XML の書き出しには影響しません。
- 音声ページで長押しして複数選択し、一括削除。
- ライブラリー・音声・設定のスクロール位置を保持し、ページから戻る時やタブ切替時に復元。
- UI 言語：English / 日本語 / 简体中文 / 繁體中文。システム設定に従うか手動で指定可能。

## プライバシー

本アプリにはネットワーク関連のコードが一切含まれていません（FFmpeg 自体も
`--disable-network` でビルドされています）。アカウント、解析、クラッシュレポートは
ありません。すべてのデータは端末内に留まります。**設定 → ローカルキャッシュを消去**は
メディアのスキャンキャッシュとサムネイルを削除します。既存の書き出しを識別できるよう、成功した書き出し記録は保持します。
